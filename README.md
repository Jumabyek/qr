# QR генератор

Тегін әрі әдемі QR код генераторы. Сервері жоқ: бәрі қолданушының браузерінде жасалады, ешқандай дерек ешқайда жіберілмейді.

**Сайт:** https://jumabyek.github.io/qr/

## Мүмкіндіктер
- 12 түр: сілтеме, мәтін, Wi-Fi, визитка, email, SMS, телефон, WhatsApp, Telegram, карта, іс-шара, әлеуметтік желі
- 8 дайын стиль, градиент, бұрыш түсі, мөлдір фон, логотип, жазуы бар жақтау
- PNG, SVG және басып шығаруға A4 PDF плакат
- Жаппай жасау: тізімнен не Excel/CSV файлынан 300 кодқа дейін, ZIP болып
- Камерамен не суреттен QR оқу
- Қазақша, монголоор, English
- Телефонға қолданба ретінде орнатуға болады, интернетсіз де істейді

## Құрамы
`index.html` (бүкіл қолданба), `sw.js` (офлайн жұмыс), `manifest.webmanifest`, `icons/`.

Кітапханалар: qrcode-generator 1.4.4, jsQR 1.4.0, JSZip 3.10.1, SheetJS 0.18.5, jsPDF 2.5.1.
